# Starter Web (HTML + CSS + JS)

Template web statis multi-halaman yang siap di-deploy ke Vercel.
Penjelasan lengkap struktur ada di **[STRUKTUR.md](STRUKTUR.md)**.

## Jalankan lokal

Klik dua kali `index.html`, atau pakai ekstensi Live Server di VS Code.

## Ganti dulu sebelum dipakai

- [ ] "Nama Proyek" di semua halaman (judul, header, footer)
- [ ] `<title>` dan `description` tiap halaman
- [ ] Warna di `assets/css/style.css` (bagian `:root`)
- [ ] `assets/images/favicon.svg` dan tambahkan `og-image.png` (1200x630 px)
- [ ] `domainmu.com` di `robots.txt` dan `sitemap.xml`

## Deploy ke Vercel

1. Unggah isi folder ini ke repo GitHub (file langsung di akar repo).
2. Vercel: Add New → Project → pilih repo → Deploy (Framework Preset: Other).
3. Setiap commit baru otomatis ter-deploy.
